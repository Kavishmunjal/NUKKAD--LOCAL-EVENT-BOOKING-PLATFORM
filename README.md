# NUKKAD – LOCAL EVENT BOOKING PLATFORM

## Project Description

Nukkad is a web-based Local Event Booking Platform developed to help users discover, explore, and book tickets for local events. The platform provides a simple and user-friendly interface where users can browse available events, search for specific events, book tickets, and even submit their own events for hosting.

The main purpose of Nukkad is to make local event discovery and booking easier through a single web platform.

## 1. Features

- Browse Events: Users can explore different local events displayed on the website.
- Search Events: Users can search for events according to their requirements.
- Filter Events: Users can filter the available event listings.
- Ticket Booking: Users can select an event and book tickets through a booking form.
- View Tickets: Users can access the ticket section to view their bookings.
- Cancel Tickets: Users can cancel previously booked tickets.
- Host an Event: Users can submit their own event details through the event-hosting form.
- Local Storage: The website uses browser localStorage to save supported booking and event information.

## 2. Technologies Used

HTML5: Used to create the basic structure and content of the website.

CSS3: Used for designing the website, including layouts, colors, buttons, forms, event cards, and responsive styling.

JavaScript: Used to implement interactive features such as event searching, filtering, ticket booking, form validation, cancellation, and event hosting.

LocalStorage: Used to store supported event and booking information directly in the user's browser.

## 3. Project Structure

```
Nukkad/

│

```

- index.html: Contains the structure and content of the website.
- style.css: Contains the design and styling of the website.

## 4. Installation and Setup

Nukkad is a front-end web development project. It does not require a backend server or database for its current version.

To run the project:

1. Download the project folder.
2. Open Visual Studio Code.
3. Select File and then Open Folder.
4. Choose the Nukkad project folder.
5. Open the `index.html` file.
6. Right-click and select Open with Live Server, if the Live Server extension is installed.
7. The website will open in your default browser.

Alternatively, users can directly open the `index.html` file in a web browser.

## 5. How to Use the Website

1. Open the Nukkad website.
2. Browse the available local events.
3. Use the search and filter options to find specific events.
4. Select an event and open the ticket-booking form.
5. Enter the required information and complete the booking process.
6. Visit the ticket section to view booking information.
7. Use the cancellation option if you want to cancel a ticket.
8. Use the Host Event section to submit details of a new event.

## 6. Data Storage

Nukkad uses the browser's localStorage feature to store supported event and booking information.

The stored information remains available when the website is reopened in the same browser and under the same website origin.

However, the data is not automatically synchronized between different devices or browsers. Clearing browser site data may also remove the saved information.

## 7. Limitations

- The current project is a front-end prototype.
- Real online payment processing is not implemented.
- The project does not have a connected backend server.
- There is no centralized database.
- Data is stored locally in the browser.
- Production-level user authentication and server-side security are not implemented.
